# Libros de análisis


## [R.HydroStormMarkerIDF.xlsm](R.HydroStormMarkerIDF.xlsm)

Código en VBA para Microsoft Excel 2019.
Se incluye hoja con ejemplo usando la estación IDEAM - PARIS DE FRANCIA [28010370] - Colombia.
Serie de datos 2010 a 2019 con 22842 registros.
Se eliminaron los ceros consecutivos en la serie para reducir el tamaño del archivo.

Nota: Los valores y gráficas presentadas corresponden a un ejemplo y no deben ser utilizados para cálculos o análisis. Es necesario evaluar los eventos atípicos de precipitación a excluir de la serie de datos para obtener la IDF ajustada de la estación utilizada.

Eventos excluidos
2011.05.20 44mm
2013.12.21 51.2mm
2014.11.12 53.9mm
